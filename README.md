# Karlsruhe WebGIS

Interactive web map of Karlsruhe built with:

- PostGIS
- GeoServer
- Leaflet
- Docker

## Features

- Roads layer
- Buildings layer
- Water layer
- Layer toggle
- Feature popup
- Styled layers
- One-click startup

## Run

```bash
git clone <repo-url>
cd karlsruhe-webmap
start.bat
```

## Access

Map:
http://localhost:8000

GeoServer:
http://localhost:8081/geoserver
